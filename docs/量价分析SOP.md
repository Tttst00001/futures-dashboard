# 量价分析 SOP（VP-1.3）

> 适用范围：`期市链条 · 商品温度看板` 品种热度表「分析」列弹窗。
> 目标：同一份数据、任何时候、任何人跑，结论一致；不允许临场改口径。
> 版本：VP-1.3（2026-11-28）。改任何阈值或判定顺序，必须同时改 `VP_SOP_VERSION` 和本文档。

## 一、数据口径

| 项 | 规定 |
|---|---|
| 数据源 | 新浪财经，主力日期合约日线（`main_daily`），不混用连续合约 |
| 最小样本 | 日线 ≥ 22 根，且当日有成交量与持仓量，否则输出"无法分析" |
| 价格 | 收盘价 |
| 成交量 | 当日成交量（手） |
| 持仓量 | 当日总持仓（手），期货不区分多空 |
| 换月 | 主力换月会造成持仓与价格跳变，跨换月的变化按原值计算，不修正 |

## 二、指标定义（全部固定）

1. **量比** = 当日成交量 ÷ 前 20 个交易日均量（不含当日）。用前 20 日而非含当日，避免"当日巨量把均值抬高"自我稀释。
2. **量能档位**（按量比）：

| 量比区间 | 档位 | 含义 |
|---|---|---|
| < 0.8 | 缩量 | 否决：不做 |
| 0.8 – 1.2 | 常量 | 中性 |
| 1.2 – 1.8 | 温和放量 | 准入 |
| > 1.8 | 巨量 | 禁追 |

3. **持仓当日变化** = 持仓量 ÷ 前一日持仓量 − 1（%）。
4. **持仓 5 日变化** = 持仓量 ÷ 5 个交易日前持仓量 − 1（%）。
5. **量仓比** = 当日成交量 ÷ 当日持仓量。
6. **价格方向** = 当日涨跌 与 5 日涨跌，两者同号记为"价仓同向"判断用的 `same_way`。

## 三、状态判定（优先级固定，从上到下第一条命中即返回）

| 顺序 | 状态 | 条件 | 动作含义 |
|---|---|---|---|
| 1 | C 缩量观望 | 量比 < 0.8 | 不做，等量能恢复 |
| 2 | B 巨量禁追 / 换手 | 量比 ≥ 1.8（一律禁追）；同时持仓当日 ≤ −1% 时表述为"换手 / 平仓" | 不追，等回踩确认 / 等缩量回踩再评估 |
| 3 | D 价涨仓减（背离） | 持仓 5 日 ≤ −3% 且 5 日价格上涨 且 当日持仓未增（< +1%） | 减仓，警惕获利了结 |
| 4 | A 新钱进场 | 量比 ≥ 1.2 且 持仓当日 ≥ +1% 且 当日与 5 日价格同向 | 可按砖图方向进场 |
| 5 | E 中性 | 以上都不满足 | 按砖图执行，量能无加分 |

判定原则：**量不负责给方向，只负责否决与禁追**；方向仍由砖图 / KDJ 决定。

## 五、结果解读（写给人看的固定话术）

| 状态 | 一句话 |
|---|---|
| A | 量能温和、持仓增加、价格同向：新钱进场，趋势有燃料。 |
| B | 量很大但持仓在掉：多空双向平仓 / 换手，涨跌都不持久，别追。 |
| C | 量能枯竭：价格再好看也缺少参与者，信号可信度低。 |
| D | 价格在涨、持仓在减：获利了结占优，涨势靠回补，不靠新钱。 |
| E | 量仓无特别信号，按砖图原规则执行。 |

## 六、一句话总结（固定模板，禁止手写改写）

弹窗状态条下方的一句话，由后端 `vp_summary()` 按模板生成，不人工编辑：

```
{MM-DD} 量比 {ratio:.2f}（{档位}），持仓当日 {±x.xx%}、5 日 {±x.xx%}，5 日价格 {±x.xx%} → {状态名}：{动作}。
```

示例（SM 2026-11-27）：

> 11-27 量比 1.69（温和放量），持仓当日 +4.89%、5 日 −14.65%，5 日价格 +3.09% → 新钱进场：可按砖图方向进场。

规则：

1. 顺序固定：日期 → 量比（档位）→ 持仓当日/5 日 → 5 日价格 → 状态 → 动作；不得调换、不得增删要素。
2. 缺失值统一写 `—`，不写"无""空""N/A"。
3. 一句话里不得出现"大概率""建议""应该"等无法证伪的措辞，也不得给目标价/仓位。
4. 与判定清单冲突时，以清单为准并视为 bug，须改代码而不是改文字。

## 七、已知限制（不许在结论里越过）

1. **持仓量是总量**，不能拆分多头平 / 空头平；"空头回补"只能作为推断，不能当事实。
2. 会员持仓龙虎榜是**会员席位汇总**，只能回答"前 20 名在减"，不能回答"某个大户在平"。
3. 分钟级成交量缓存存在缺失（尾盘 bar 量常被截断），**不用分钟量做归因**，只用日线。
4. 量价结论只做**信号准入 / 禁追 / 减仓**，不单独产生开仓方向。
